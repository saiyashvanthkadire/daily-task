# Daily Task Planner

A clean and responsive browser-based task management app for organizing your daily work. It helps you add, edit, complete, search, filter, and remove tasks while keeping everything saved in the browser using local storage.

## Features

- Add new tasks with title, priority, category, and optional due time
- Mark tasks as complete or pending
- Edit tasks inline without leaving the list
- Search tasks by title or category
- Filter tasks by status and priority
- Clear completed tasks in one click
- View productivity stats and progress percentage
- Light and dark mode toggle
- Persistent storage using browser localStorage

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons

## Project Structure

- `index.html` — app layout and UI structure
- `style.css` — custom styles and theme design
- `script.js` — task logic, rendering, filters, persistence, and interactivity

## Usage

- Enter a task in the input field and click Add Task.
- Use the filter buttons to view all, pending, or completed tasks.
- Use the search box to quickly locate a task.
- Click the check button to complete a task.
- Use the edit button to update a task title inline.
- Use the delete icon to remove a task.

## Notes

This app stores data locally in the browser, so tasks remain saved on the same device/browser until cleared or removed.
